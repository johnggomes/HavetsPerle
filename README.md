# Padborg Fish Works

Investor brief for a Havets Perle fish production and cold-logistics facility at Padborg.

The whole site is one file, `index.html`. To publish with GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.

All figures are working assumptions. Edits made on the Assumptions tab stay in the viewer's own browser; use "Download numbers as JSON" to keep a copy.
